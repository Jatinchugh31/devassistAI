## 💡 Quick Reference Cards

### **ReAct Pattern Quick Reference**
```
ReAct Loop:
1. THINK: "I need to..."
2. ACT: Execute tool
3. OBSERVE: Get result
4. THINK: "Now I should..."
5. ACT: Execute next tool
6. ...repeat until goal achieved
```

### **Planning Pattern Quick Reference**
```
Planning Flow:
1. PLAN: Break task into steps
2. EXECUTE: Run each step
3. REFLECT: Evaluate results
4. ADJUST: Modify plan if needed
5. EXECUTE: Continue with adjusted plan
```

## 📌 Notes for Implementation

### **Key Concepts to Understand:**
- ✅ **ReAct Loop**: Think → Act → Observe → Think → ...
- ✅ **Planning**: Break complex tasks into steps
- ✅ **Tool Orchestration**: Chain multiple tools together
- ✅ **Reasoning Trails**: Capture AI thinking process
- ✅ **Autonomous Execution**: Agent runs without prompts

### **Spring AI Specific:**
- ✅ **ChatClient**: Main interface for AI calls
- ✅ **@Tool Annotation**: Makes methods callable by AI
- ✅ **Advisors**: Intercept and modify prompts/responses
- ✅ **Function Callbacks**: Tool execution mechanism
